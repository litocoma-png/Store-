# Kareth Store Manager — installable app

Works offline. Install on phones and computers like software.

## Quick start (USB / folder)

1. Unzip into one folder.
2. Open `index.html` in Chrome or Edge.
3. Use the app immediately (data saved in that browser).

## Install as software (home screen / Start menu)

Install needs the app on **HTTPS** once (then it works offline).

### Free hosting (GitHub Pages)

1. Create a GitHub account and a new repository.
2. Upload all files from this zip into the repo.
3. Settings → Pages → Deploy from branch `main` / root.
4. Open the HTTPS link (e.g. `https://yourname.github.io/repo/`).

### Then install on the device

| Device | How to install |
|--------|----------------|
| **Android** | Chrome → menu (⋮) → **Install app** or **Add to Home screen** |
| **Windows** | Chrome or Edge → install icon in address bar, or menu → **Install** |
| **Mac** | Chrome or Edge → menu → **Install Kareth Store** |
| **iPhone / iPad** | **Safari** → Share → **Add to Home Screen** |

After install, open the app from the home screen or app list. It runs full-screen and offline.

## Features

- Products, pricing, sales, reports
- Multi-product credit + editable due date
- Custom store name and tab labels
- Backup / restore JSON (move data between devices)
